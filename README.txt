STAR MAZE — RAGE RUN V5

THIS VERSION STARTS FROM THE ORIGINAL GIANT-MAZE V4 CODE.

WHAT WAS CHANGED
- The Giant Maze design is kept.
- The carved paths are expanded to 2-tile-wide floor sections.
- Traps now move vertically from top to bottom and back up.
- Traps pause for about 1.25 seconds at the top and bottom.
- The five original local MP3 files are still used.
- Sound is unlocked by the first click/key press and can be turned on/off.
- Classic, Challenge, Endless, Time Attack, Practice and Legacy modes.
- Levels continue forever; there is no final level.
- Checkpoints, boosts, secret passages and fake exits remain.
- TinyD congratulates the player after every successful level.
- High scores are saved in localStorage.
- Simple cosmetic player skins were added.
- Settings, skins, high scores, about and exit menu screens were added.
- The JavaScript is deliberately spaced vertically and heavily commented.

THE FIVE REAL SOUNDS
1. Danger: the-saxophones-getting-louder.mp3
2. Trap touch: slap-oh_LGvkhyt.mp3
3. Level complete: somebody-say-merlin.mp3
4. Get trapped: chicken-on-tree-screaming.mp3
5. Boost: run-vine-sound-effect.mp3

TRAP AUDIO
When a trap is hit, the Slap plays immediately and the Chicken scream follows shortly after.

HOW TO RUN
Open index.html in a browser, or use VS Code + Live Server.
Keep the assets/sounds folder beside index.html and game.js.

NOTE ABOUT INFINITE LEVELS
The level number can continue forever. The physical maze size is kept within a browser-friendly limit while trap count and difficulty continue increasing.
